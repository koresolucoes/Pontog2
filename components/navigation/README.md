# Navigation components

## PulseDock

Primary authenticated navigation for Ponto G. The dock is intentionally limited to the five core destinations: Explore, Map, Agora, Conversations and You.

## ContextBar

Context-aware top chrome for the same destinations. Account/settings are opened from the avatar, keeping the sidebar as a secondary account center instead of a competing primary navigation.

## Product rule

Feature screens should not create a second persistent navigation layer. Screen-specific headers may add local actions, but they should visually defer to the App Shell and avoid duplicating the page title when the Context Bar is visible.
